# Basilico Coffee House — Artisanal Roastery & Cafe

A responsive web application and digital storefront for **Basilico Coffee House**, featuring artisanal coffee roasts, seasonal tasting menus, table reservations, private event bookings, e-commerce shop, and cafe journal.

---

## ☕ Project Overview

- **Business Name:** Basilico Coffee House
- **Specialty:** Single-origin artisanal coffees, cold brews, loose-leaf teas, and fresh morning pastries
- **Location:** Shop 14, Block C, Inner Circle, Connaught Place, New Delhi 110001, India
- **Contact:** +91 98765 43210 | hello@basilicocoffee.com | reservations@basilicocoffee.com

---

## 🛠️ Technology Stack

- **Markup & Structure:** Semantic HTML5
- **Styling:** Custom CSS3 with Responsive Breakpoints (Bootstrap Grid 5 & Mobile Flexbox)
- **Typography:** DM Sans (Google Fonts) & Oswald (Locally Hosted)
- **Interactivity:** Vanilla JavaScript & jQuery 3.6
- **Carousels & Sliders:** Swiper.js
- **Icons:** Custom IcoMoon Icon Font
- **Animations:** WOW.js & Animate.css

---

## 🚀 Running Locally

No heavy build steps or package managers required. You can serve the static site using any local web server:

### Option 1: Using Node.js (Built-in)
```bash
npx serve .
```
Or start with Python:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` or `http://localhost:3000` in your web browser.
